DOWNLOAD & SETUP

Pick your platform.

The Windows desktop and Android apps are in development. Public installers are not available yet.

In development

Windows

64-bit x64 PC · Desktop installer

  1. Download the setup file from GitHub Releases once it’s published, then run it. The installer includes the app and model runner; no Git, Python setup, or admin access is needed.
  2. Open Frankesso from Start using the bunny icon.
  3. Get the Qwen3-4B model file (2.5 GB) separately. Paste the full local path and choose Import model. Frankesso itself does not download it.
In development

Android

Android 8.0+ · 64-bit ARM phone

  1. Download and install the APK from GitHub Releases once it’s published. The APK includes the model and is about 504 MB. After installing, keep at least 525 MB free so Frankesso can prepare the model.
  2. Open Frankesso from your app drawer and chat offline. There’s no separate model download or import.
